# Daniel's Infinite Marble Run

## Introduction
For my Kinematic Art Project, I create an infinite marble run, where a marble uses gravity to fall through a series of tracks, ultimately being brought back to the start of the loop with DIY marble lifts. Since this project ultimately involved zero code, I will use this README as a place to list all components of the project, including STL files 3D printed parts, so that anybody can recreate the project on their own.
